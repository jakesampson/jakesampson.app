# jakesampson.github.io

This is the raw code for my Personal Website: jakesampson.com.au
Hosted here on github. 

Contact me at jakesampson98@gmail.com for any personal enquiries.

The homepage includes an interactive spatial demo with an imaginary railway,
including stations, level crossings, bridges, a signal and a depot. Select a
point and a search radius from 100 m to 10 km to find nearby features. The
illustrated map represents a 21 km-wide region, with a scale bar for distances;
roads, tracks, rivers and feature markers are symbols rather than actual widths.
Distances are straight-line rather than along the tracks. The demo runs locally
without a map service or saved location data.
