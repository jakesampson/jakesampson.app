# jakesampson.github.io

This is the raw code for my Personal Website: jakesampson.com.au
Hosted here on github. 

For personal enquiries, connect with me on LinkedIn.

The homepage includes an interactive EV range demo on a Queensland-inspired
regional map. Choose a starting point to snap to a road, then adjust the
available range (50–600 km, default 350 km) to see reachable roads and
fictional charging stations with their route distances. The map uses a 200 km
scale bar and runs locally without a map service or saved location data.
